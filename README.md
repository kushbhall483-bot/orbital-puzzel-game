# 🎮 Orbital Puzzle

A relaxing yet challenging **ball-sorting puzzle game**, built entirely for the browser. Sort colored balls into matching tubes, one smooth move at a time — simple to learn, surprisingly hard to master.

## 🕹️ About the Game

Orbital Puzzle takes the classic ball/color-sort puzzle concept and brings it to life with a clean, minimal interface and smooth animations. The goal is simple: move balls between tubes until each tube contains only one color. Sounds easy — until the levels get trickier!

This project started as an experiment using Google AI Studio and was rebuilt, customized, and deployed independently as a full browser game.

## ✨ Features

- 🌈 Colorful, intuitive ball-sorting gameplay
- 🎯 Increasing difficulty as you progress
- ⚡ Smooth animations and responsive controls
- 📱 Works directly in the browser — no downloads needed
- 🖥️ Clean, distraction-free UI

## 🛠️ Tech Stack

- **Language:** JavaScript / TypeScript
- **Deployment:** Vercel

## 🎯 How to Play

1. Click a tube to select the top ball
2. Click another tube to move the ball there
3. A ball can only be placed on an empty tube or on top of a matching color
4. Sort all balls by color to win the level!
